# CYBER SWARM - Project Instructions

## Overview
Roguelike bullet-heaven cyberpunk game. Canvas 2D com object pooling, spatial grid para colisão, sons procedurais via Web Audio API.

## Visual Style
- Dark background: #0A0A12
- Neon cyan: #00FFFF (primary)
- Neon magenta: #FF00FF (secondary)
- Neon green: #00FF88 (accent/XP)
- Font: JetBrains Mono only
- All UI text in Portuguese (pt-BR)

## Architecture
- `lib/game/engine.ts` — GameEngine class with full game loop, rendering, collision
- `lib/game/types.ts` — TypeScript interfaces
- `lib/game/constants.ts` — Weapon/enemy/character definitions
- `lib/game/audio.ts` — Procedural audio via Web Audio API
- `components/game/cyber-swarm.tsx` — Main client component with React overlays
- `components/game/game-loader.tsx` — Dynamic import wrapper (ssr:false)
- `app/api/scores/route.ts` — High score CRUD API with Prisma

## DB Schema
- HighScore: id, name, kills, time, character, level, createdAt

## Key Decisions
- Canvas 2D (not WebGL) for simplicity and compatibility
- Object pooling for projectiles, particles, enemies, XP orbs
- SpatialGrid for efficient collision detection
- ssr:false must be in a 'use client' component, not server page

## Desktop / Steam Packaging
- The game can be shipped as a standalone desktop .exe (runs 100% offline, no browser/server).
- Build pipeline used:
  1. Isolated static export workspace at `/home/ubuntu/cs_export` (copy of source, node_modules symlinked to real /opt path, own next.config.js with `output:'export'`, `outputFileTracingRoot:'/'`, `assetPrefix:'./'`; api route + lib/db.ts removed; layout without force-dynamic/external script). Build with `./node_modules/.bin/next build` → static site in `.export-build/`.
  2. Electron wrapper at `/home/ubuntu/cyber_swarm_desktop`: `main.js` runs a tiny internal Node http static server serving `game/` on 127.0.0.1 ephemeral port, loads it in a BrowserWindow. No runtime deps beyond electron.
  3. Package with `@electron/packager` → `--platform=win32 --arch=x64` (works on Linux WITHOUT wine for unpacked build). Output: `dist/Cyber Swarm-win32-x64/Cyber Swarm.exe`.
- Steam does NOT need an installer — upload the unpacked folder to a depot via SteamPipe and set launch exe.
- Deliverables in `/home/ubuntu/output/`: CyberSwarm-Windows.zip (111M), cyber_swarm_desktop_source.zip, COMO_JOGAR_E_PUBLICAR.md/pdf/docx.
- Config files (next.config.js, package.json) are write-blocked by tool name globally — must write via bash heredoc.
