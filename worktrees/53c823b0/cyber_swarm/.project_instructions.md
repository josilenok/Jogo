# CYBER SWARM - Project Instructions

## Overview
Roguelike bullet-heaven cyberpunk game. Canvas 2D com object pooling, spatial grid para colisão, sons procedurais via Web Audio API.

## Visual Style
- Dark background: #0A0A12
- Neon cyan: #00FFFF (primary)
- Neon magenta: #FF00FF (secondary)
- Neon green: #00FF88 (accent/XP)
- Font: JetBrains Mono only
- All UI text in Portuguese (pt-BR)

## Architecture
- `lib/game/engine.ts` — GameEngine class with full game loop, rendering, collision
- `lib/game/types.ts` — TypeScript interfaces
- `lib/game/constants.ts` — Weapon/enemy/character definitions
- `lib/game/audio.ts` — Procedural audio via Web Audio API
- `components/game/cyber-swarm.tsx` — Main client component with React overlays
- `components/game/game-loader.tsx` — Dynamic import wrapper (ssr:false)
- `app/api/scores/route.ts` — High score CRUD API with Prisma

## DB Schema
- HighScore: id, name, kills, time, character, level, createdAt

## Key Decisions
- Canvas 2D (not WebGL) for simplicity and compatibility
- Object pooling for projectiles, particles, enemies, XP orbs
- SpatialGrid for efficient collision detection
- ssr:false must be in a 'use client' component, not server page
